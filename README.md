# Angel Lounges · IPPC 2025

Guest management for the Angel Lounge at Angel Court: partner invitations, self-registration with tier-coloured QR passes, and lounge check-in.

**Stack:** Laravel 12 · Inertia.js 2 · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui (Radix)

## What's where

| Area | URL | Code |
| --- | --- | --- |
| Partner registration (public) | `/partner/register/{token}` | `PartnerRegistrationController`, `resources/js/pages/partner/*` |
| QR verification (public) | `/partner/verify/{id}` | same |
| Staff sign-in | `/login` | `Workspace\AuthController` |
| Workspace | `/workspace` | `app/Http/Controllers/Workspace/*`, `resources/js/pages/workspace/*` |
| Scanner app API | `/api/*` | `CheckInController`, `PartnerVerificationController` (unchanged) |

### The workspace

- **Home** — the guest journey (on the list → delivered → registered → checked in), things that need attention, lounges by tier, live activity.
- **People** — every partner as a board (grouped by journey or by lounge), cards, or a list. Click anyone to open their profile: details, QR pass, journey timeline, edit, resend, new link, delete. Select several for bulk QR codes, resends or removal.
- **Check-ins** — live arrivals from the scanners, 7-day chart, Excel report download.
- **Outreach** — email whole lounges at once; delivery health and one-click retries for bounced emails.
- **Import** — drag in the Excel/CSV guest list; everyone new is invited automatically.
- **Team** — who can sign in.

Press <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> anywhere to search partners or jump around; <kbd>G</kbd> then <kbd>H</kbd>/<kbd>P</kbd>/<kbd>C</kbd>/<kbd>O</kbd> to switch pages; <kbd>F</kbd> to search on People.

## Running it

```bash
composer install
npm install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed          # creates the admin users from UserSeeder
php artisan storage:link
composer run dev                    # server + queue worker + Vite
```

Optional fake data for a local preview (never on production):

```bash
php artisan db:seed --class=DemoSeeder
```

QR codes are PNGs generated by `simplesoftwareio/simple-qrcode`, which needs the PHP **imagick** extension. Emails are sent by queued jobs, so a queue worker must be running (`php artisan queue:work`).

## Deploying

The frontend is now compiled by Vite, so every deploy needs a build step:

```bash
composer install --no-dev --optimize-autoloader
npm ci && npm run build
php artisan migrate --force
php artisan optimize
```

## Tests

```bash
php artisan test     # feature tests for the workspace, registration and scanner API
npm run types        # TypeScript check
```
